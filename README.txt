PYTHON CAREER TRACKER — ANDROID SETUP

What is included:
- Mobile-friendly 6-month roadmap
- Daily checklists, completion percentage, streaks
- Study-time and blocker check-in
- Local-device progress storage and JSON export
- PWA manifest and basic offline cache

IMPORTANT:
This is a web app prototype, not a signed APK. It stores progress in the browser on the device. Clearing browser/site data may erase it, so export progress periodically.
Daily notifications are limited by Android/browser rules and generally need the app hosted over HTTPS and installed. For reliable daily reminders, set a recurring 7 PM alarm/reminder in your phone's Clock or Calendar app.

EASIEST WAY TO USE:
1. Extract the ZIP on a computer.
2. Host the folder on an HTTPS static hosting service (for example GitHub Pages or Netlify).
3. Open the HTTPS link in Chrome on your Android phone.
4. Chrome menu (⋮) > Add to Home screen / Install app.
5. Open it from the new home-screen icon.
6. Tap Reminders if you want to check notification permission; also set a daily phone alarm.

If you only open index.html directly from a file manager, basic checklist features may work, but install/offline/notification features may not.
